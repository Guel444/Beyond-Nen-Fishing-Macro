BEYOND NEN FISHING MACRO — GUIA RÁPIDO
========================================

1. EXTRAIR
   Extraia todo o conteúdo do arquivo ZIP para uma pasta.
   Não execute o programa diretamente de dentro do ZIP.

2. ABRIR
   Dê dois cliques em BeyondNenFishing.exe.
   Não é necessário instalar Python.

3. PREPARAR O JOGO
   Abra Beyond Nen no Roblox, equipe sua vara no slot configurado
   no macro e mantenha a janela do Roblox em primeiro plano.

4. CONTROLAR
   F6 — iniciar ou pausar a pesca automática
   F7 — parar a automação e soltar o botão do mouse
   F8 — mostrar ou ocultar a prévia da tela

5. AJUSTAR, SE NECESSÁRIO
   Use as opções da janela do macro para selecionar a região do
   minigame e escolher o slot da vara (1 a 9).

REQUISITOS
- Windows 10 ou Windows 11 (64 bits).
- Python não é necessário para esta versão pronta.
- Roblox deve permanecer em primeiro plano durante a automação.

AVISO DO WINDOWS
Executáveis sem assinatura digital podem exibir um aviso do SmartScreen.
Antes de prosseguir, confirme que o ZIP foi baixado da página oficial.
Não desative o antivírus. Se necessário, verifique o arquivo com o
Microsoft Defender.

ENGLISH
1. Extract the entire ZIP archive to a folder. Do not run the app from inside the ZIP.
2. Double-click BeyondNenFishing.exe. Python is not required.
3. Open Beyond Nen in Roblox, equip your rod in the configured slot, and keep Roblox in the foreground.
4. F6 starts/pauses, F7 stops, and F8 shows/hides the live preview.
5. Use the app settings to select the minigame area and rod slot (1–9), if needed.

Requirements: Windows 10/11 (64-bit). Roblox must stay in the foreground.
